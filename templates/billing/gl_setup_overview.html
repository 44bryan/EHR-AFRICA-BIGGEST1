Operations

Each operation defines an accounting event (e.g. "Ventes Optique", "Stock Entry Pharmacie"). It holds the default Dr/Cr accounts and which cost center to assign on Class 6 & 7 lines.

View All + New
Entry / Exit Types

Each store movement (stock in / stock out) has a type that sets the Dr/Cr accounts and links to an operation for cost center tagging. Filtered per store type.

View All + New
Item GL Routing

When the cashier invoices a product/service, the system uses the item's category to automatically pick the right Revenue (7xx), COGS (6xx) and Stock (3xx) accounts.

Cost Centers

Analytical accounting departments (e.g. CC:009 Optical, CC:008 Pharmacy). Assigned automatically on Class 6 & 7 journal lines only — never on Class 3/4/5.
