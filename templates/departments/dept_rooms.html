How it works
  1. Add all door numbers for {{ dept.name }} once (e.g. 1, 2, 3).
  2. Set each room's tier (Standard/Express/VIP) — VIP rooms route to the VIP consultation queue.
  3. Each morning, assign which doctor is in each room. The triage nurse sees "Room 5 — Dr. Johnson [VIP]".
  4. Selecting a VIP room automatically dispatches to VIP_CONSULT and assigns the room's doctor to the token.
  5. If no rooms are configured, patients go to the general department queue.
