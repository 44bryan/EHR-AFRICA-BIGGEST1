Standard Patient Flow

New or returning patient · General ophthalmology consultation · Pay-at-cashier model
Flow TypeStandard Avg Duration45 – 90 min Starts AtHospital Gate Ends AtPharmacy / Exit QMSRequired

Step-by-Step Procedure

  1. 1
    Patient Arrives at Hospital Gate
    Gate Staff / Security
    System screen: QMS → Gate Ticket Issue
    Gate staff asks patient purpose of visit and opens the Gate Issue screen.
    • Select patient type: New or Returning
    • Select destination: OPD / Consultation
    • Print or show QMS ticket slip to patient
    • Direct patient to the Registration / Reception counter
  2. 2
    Registration / Patient Check-In
    Receptionist
    System screen: Patients → Register or Patients → Search
    • New patient: Fill full registration form (name, DOB, phone, address, next-of-kin, ID)
    • Returning patient: Search by name or Patient ID → open record
    • Confirm or update contact details
    • Assign or confirm Visit for today
    • Call next QMS number when done
  3. 3
    Triage — Vitals & Chief Complaint
    OPD / Triage Nurse
    System screen: Consultations → Triage Workstation
    • Open patient in Triage Workstation using QMS queue or search
    • Record: Visual Acuity (VA) — right eye, left eye (unaided and aided)
    • Record: Intraocular Pressure (IOP), blood pressure, weight if relevant
    • Record: Chief Complaint (reason for visit)
    • Note any known allergies or urgent symptoms
    • Click Submit Triage — patient enters doctor queue automatically
  4. 4
    Doctor Queue — Patient Waiting
    QMS Display / Nurse Dispatcher
    System screen: QMS → Doctor Queue
    Patient waits to be called. Display board shows ticket number and room assignment. Nurse/dispatcher calls next patient from the doctor queue screen.
  5. 5
    Doctor Consultation
    Ophthalmologist / Doctor
    System screen: Consultations → Workstation
    • Open patient from the queue — pre-populated with triage vitals
    • Select Consultation Type (Gen Ophthalmology, Retina, Glaucoma, etc.)
    • Complete clinical examination form — anterior segment, posterior segment, refraction
    • Add Diagnosis (ICD-10 codes)
    • Issue orders as needed:
      • Drug Prescription → goes to Pharmacy
      • Lab Order → goes to Laboratory
      • Investigation Order → goes to Imaging / Investigations
      • Optical Prescription → goes to Optical Dispenser
    • Click Complete Consultation
    • Optionally book Follow-up Appointment
  6. 6
    Billing — Payment at Cashier POS
    Cashier
    System screen: Billing → Cashier POS or Billing → Work Queue
    • Search patient by name or Patient ID
    • Pending charges appear automatically (consultation fee + any ordered services)
    • Select payment method: Cash / Mobile Money / Card
    • Process payment → system generates Receipt
    • Print or show digital receipt to patient
  7. 7
    Pharmacy — Medication Dispensing
    Pharmacist
    System screen: Pharmacy → Dispensing Queue
    • Prescription appears in dispensing queue after payment confirmation
    • Pharmacist reviews drug list, checks for interactions (system flags alerts)
    • Dispense medications and mark as dispensed in system
    • Counsel patient on dosage and instructions
  8. 8
    Laboratory / Investigations (if ordered)
    Lab Technician / Investigation Tech
    System screen: Investigations → Workstation or Laboratory → Dashboard
    • Patient goes to lab or imaging unit with order slip / QMS ticket
    • Tech locates order in their workstation queue
    • Perform test / capture images
    • Enter results into system → report auto-linked to patient record
    • Doctor receives notification of completed results
  9. 9
    Patient Exit / Discharge
    Receptionist / Gate Staff
    System: Visit marked Completed automatically on payment
    • Patient collects medication from pharmacy
    • If follow-up was booked, patient receives appointment card / SMS
    • Patient exits — QMS token closed
Dry Run Checklist: Verify QMS display is working → Registration can create patient → Triage workstation is accessible to nurse → Doctor queue loads → POS processes a test payment → Pharmacy queue shows prescription after payment.
Key Rule: Payment must be completed before pharmacy releases medication. The system enforces this — prescriptions only appear in the dispensing queue after the invoice is marked PAID.
