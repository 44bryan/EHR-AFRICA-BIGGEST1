{# Auto-billing routing fees #}
Auto-Billing on Patient Routing

When a doctor or nurse routes a patient to a billable service (e.g. Refraction, Cycloplegic Refraction, Orthoptics), the system automatically adds the fee to the patient's invoice. Duplicate charges are prevented. You control which services are billable and their prices from the Price Catalog.

Backup Configuration

Automated full backups run daily at 02:00 via Celery Beat. You can also trigger a backup manually.

{% csrf_token %}
Backups older than this are automatically deleted
Change BACKUP_DIR in .env file to move it
Backup Types
  • Full backup — runs nightly at 02:00, stores entire PostgreSQL database as .dump
  • Incremental (WAL) — requires PostgreSQL WAL archiving configuration on the server (contact IT)
  • Manual backup — click "Run Backup Now" below at any time
