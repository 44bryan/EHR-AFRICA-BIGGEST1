How zones work
  • Each patient tier (Standard, Express, VIP) maps to exactly one zone.
  • When a ticket is issued, the zone is set automatically — staff never choose it manually.
  • Shared Services Zone (Lab, Pharmacy, OCT, Optical) serves all tiers with priority ordering: VIP is served first, but a Standard patient waiting more than 45 minutes gets an automatic priority boost so they are never stuck indefinitely.
  • VIP patients appear only in VIP zone queues, screens, and staff dashboards — they are never visible in other zones.
  • To move Express patients to the Standard Zone (e.g. if the express section is temporarily closed), just change the Express mapping above — no code changes needed.
  • Run python manage.py seed_zones to reset zones to hospital defaults at any time.
